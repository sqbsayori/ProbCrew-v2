# ADR-0006 · 前端冒烟的验收方法：静态面进门禁，渲染面留人工

- **状态**：已接受（2026-09-27 于本仓作出）
- **决策人**：R1（架构与集成）
- **相关**：`docs/01` N4 / N8 · `docs/02 §1.6` 的 R-F / R-G / R-I · `docs/03 §3.1` · `docs/04 §7` 校验⑦ · `docs/06 §8` 的"落在哪"列 · `docs/06 §14.5` 检查点第 2 条 · ADR-0001

---

## 背景

三条可访问性与契约渲染纪律在 `docs/02 §1.6` 都写着"**可自动**：前端冒烟"，`docs/06 §8` 的
"落在哪"列也写着"前端冒烟（R-F①② / R-G / R-I）"。**但全仓没有一处说过"冒烟怎么跑"** ——
`docs/06 §11` 的 W5 行把它列为交付物，方法是空的；`docs/03 §8.2` 的脚本清单里也没有第二个入口
（README 的门禁节写明"新前端入口"只可能是 `verify.sh` 的一节）。

同时，这四条判据的性质并不一样：

| 判据 | 它其实要求什么 |
|---|---|
| R-F① 点击目标 ≥ 32px | **渲染尺寸**（只有真布局过才知道） |
| R-F② 键盘可达 + 语义标签 | **交互行为**（要派发事件） |
| R-G URL 可寻址 + `hashchange`/`popstate` 有监听 | 一半是**静态可判**（监听注册在不在），一半是**行为**（跳转真的发生了吗） |
| R-I `must_render` 字段必须渲染 | **渲染结果**（要读 DOM） |

硬约束有三条，且都不是新定的：**ADR-0001**（免构建 ESM · 零 npm）· `docs/01` N4（免安装）·
`docs/04 §7` 校验⑦（前端无外部依赖、无 CDN）。`docs/01` N8 已经为"**渲染结果**"记过一次同类降级
（对比度**只对声明的色对**可自动，渲染结果不在验收内）—— 本决策与它同族。
另一条事实：`.github/workflows/ci.yml` 里**只有 Python 步骤**，没有任何 Node 工具链。

## 决策

1. **门禁里不引入无头浏览器。** `scripts/verify.sh` 新增"前端冒烟（静态面）"一节，只接**静态可判**
   的四条：① `index.html` 有 DOM 挂载点 `#app-main`；② 从 `index.html` 起沿 `import` 图**逐文件存在**
   （同源托管下"存在"即"不会 404" ⇒ 白屏级故障）；③ `core/router.js` 里真的有
   `addEventListener('hashchange' | 'popstate')` 的**注册**；④ 外壳与页面样式里真的用到
   `var(--target-min)`（N8① 的**声明面**）。★ 第 ③ 条的"认注册、不认词出现过"是反向演示当场抓出来的
   （第一版写 `"hashchange" in text`，"监听被删掉、只剩注释与 `removeEventListener`"照样通过）。
2. **渲染面明确留人工。** R-F①（真实尺寸）· R-F②（键盘可达与语义标签）· R-G（跳转**是否真的发生**）·
   R-I（`must_render` **是否真的上屏**）**不在门禁内**，由 `docs/06 §14.5` 检查点第 2 条
   "**端到端走一遍并刷新页面**"的人工验收覆盖。★ 它们**逐条打印**在门禁的**覆盖台账**里 ——
   这正是"没查什么"必须看得见的既有制度（`[SKIP]` 与台账）。
3. **不做"弱代理冒充断言"。** 静态面**不**声称自己覆盖了渲染面；台账把两者分开写。

## 考虑过的替代方案（以及为什么不选）

| 备选 | 为什么不选 |
|---|---|
| **Playwright / Puppeteer** 进 CI | 同时违反 ADR-0001（零 npm）、N4（免安装）与校验⑦（无外部依赖）：要把 npm 与浏览器二进制带进一个"答辩现场双击就能开"的仓。★ 它还把 CI 从"装 Python 依赖"变成"装浏览器" |
| **纯 grep 冒充 R-F①**（把 `--target-min` 当断言） | 把**渲染面**伪造成自动 —— 本仓已经三次实测过这个形态（README 的"门禁与 CI"节 · `docs/05 §7.2`），每一次的结论都是"门禁看起来比实际更强" |
| **Python 里的 DOM 模拟**（自写 mini-DOM 跑前端） | JS 引擎不是 Python；要真跑就得引入 Node ⇒ 回到上一条 |
| **浏览器端自检模块**（`?selftest=1` 时在页面里断言并打印一行 `SELFTEST: PASS/FAIL`） | **不否定它**：它是**人工演示**的好手段（阶段门 B / C 时打开页面看一眼），但**不进 CI** —— CI 里没有人看 DOM，它只会变成一个永远 nobody 读的输出 |

## 后果（明账）

- **渲染面在阶段门 B 期间没有自动门**：R-F①② / R-G（行为）/ R-I 四条只能靠人。这与 `docs/01` N8③
  的处置同族，已在需求篇记账；`docs/06 §8` 的"落在哪"列与门禁台账**两处都这么写**。
- **反向的好处是实的**：模块 `import` 写错、挂载点被删、路由监听没接、尺寸令牌没被用 ——
  这四类真实故障从此**每次提交都查**，且都是**静态可判、零安装**的。
- **若将来真的要无头浏览器**（例如答辩要做自动化演示）：**必须新开一个 ADR，并同步 ADR-0001 的
  "免构建 / 零安装"前提** —— 不允许为了一个 demo 在 CI 里偷偷加一个 npm。
